# BrickFeed

App web progressiva (PWA) per seguire le tue fonti di notizie preferite in un unico feed e preparare rapidamente i contenuti per i tuoi post.

- Feed unificato con ricerca, filtri e notizie salvate
- Copia rapida della caption con hashtag personalizzati
- Avvisi per le nuove notizie (badge e notifiche)
- Le fonti si configurano in app e restano salvate solo sul tuo dispositivo
- Installabile su iPhone e Android, dark mode automatica

Nessuna dipendenza esterna: basta un hosting statico qualsiasi.
